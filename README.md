Week 4 JavaScript Advanced – Student Management Dashboard
📌 Project Description
This project is developed as part of Week 4 – JavaScript Advanced.

The project demonstrates important JavaScript concepts such as:

Local Storage

Email Validation

API Fetch

ES6 Arrow Functions

CRUD Operations

Search and Filter

Dynamic HTML Table

Student Management

Data Persistence using Local Storage

🚀 Features
1. Local Storage
Stores the user's name in the browser's Local Storage.

The saved name remains available even after refreshing the page.

2. Email Validation
Validates whether the entered email address is in a correct format using JavaScript.

3. API Fetch
Fetches a random quote from an API using JavaScript fetch() and displays it on the webpage.

4. ES6 Arrow Function
Uses an arrow function with the filter() method to find numbers greater than 50.

Example:

const result = numbers.filter(number => number > 50);
5. Student Management Dashboard
The dashboard allows users to:

Add students

View students

Edit student information

Delete students

Search students

Filter students by gender

Store student data in Local Storage

6. Search and Filter
Students can be searched using:

Student ID

Name

Age

Email

Gender

Course

Phone number

If no matching student is found, the dashboard displays:

❌ Data not found

7. Data Persistence
Student information is stored using browser Local Storage, so the data remains available after refreshing the webpage.

▶️ How to Run
Download or clone this repository.

Open the project folder in Visual Studio Code.

Open index.html.

Run the file using a browser or Live Server.

Use the Student Management Dashboard to add and manage students.

🔍 Search Example
Enter a student's name, email, course, phone number, age, or ID in the search box.

Example:

Search: Shareef
The matching student information will be displayed in the table.

If there is no matching information:

❌ Data not found
💾 Local Storage
The project uses Local Storage to save:

localStorage.setItem()
and retrieve data using:

localStorage.getItem()
Student objects are stored as JSON data.
